# expert-question-brief — 整理待問專家內容

## 觸發時機

使用者要把整理好的發現（review 結果、落差分析、安全稽核、待確認的架構決策等）拿去跟外部專家/顧問確認時。

## 核心規則

**不建立 .md 檔案。** 直接把整理好的內容作為文字回覆輸出在對話裡，讓使用者可以直接複製貼上拿去問專家。

- 不使用 Write 工具建立檔案
- 若中間過程需要暫存（例如先用 Agent 蒐集多份資料再彙整），暫存可以放 scratchpad，但**最終交付給使用者的一定是文字訊息**，不是檔案路徑
- 不要說「已整理好，存在 xxx.md」這種話——使用者要的是可以立刻複製走的內容，不是要自己再開檔案

## 格式

- 用清楚的標題分段（可用文字型的標題如「A. XXX」「B. XXX」，不必依賴 markdown 檔案語法）
- 每個項目附上具體依據：檔案路徑、行號、commit hash——專家沒有本地環境可查，內容要自足
- 有明確結論的（已查證、已排除）要講清楚結論，不要只丟一堆疑問句
- 結尾若有優先順序建議，列出來，但標註「未定案，待專家確認」

## 適用範圍

這個 skill 只管「輸出形式」，內容本身的深度/準確度仍照當下任務的其他 skill（如 security-audit）或一般判斷來源產出。
